Quick Start

Get Vokara running in under a minute.

1

Clone & Configure

Copy the environment template and adjust settings for your phone provider and LLM.

2

Launch with Docker

One command starts the bot, STT, LLM gateway, and TTS engine.

3

Connect Your Phone System

Point Twilio / Asterisk / FreeSWITCH at the bot WebSocket URL and answer calls.

# Clone & enter
$ git clone https://github.com/OneByJorah/vokara.git
$ cd vokara

# Configure environment
$ cp .env.example .env
$ vim .env # set DEMO_MODE=false + LLM_BACKEND for real calls

# Deploy
$ docker compose up -d

# Or run locally
$ pip install -r bot/requirements.txt
$ python3 bot/server.py
